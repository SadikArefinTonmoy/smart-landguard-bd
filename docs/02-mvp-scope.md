# MVP scope

## Feasible MVP

The initial release should focus on demo-safe, realistic functionality.

### Included

- landing page and role-based auth UI
- property search page with synthetic data
- property profile showing identifiers and risk summary
- document upload page and extracted-field review
- ownership timeline section
- mutation, dispute, and acquisition panel
- risk assessment engine with explainable flags
- buyer dashboard and purchase checklist
- admin moderation stub and audit log
- notifications and demo synthetic records

### Excluded from MVP

- real government integration
- live e-mutation access
- bank or legal payment workflows
- official land title certification
- true geospatial acquisition analysis with government parcel data

## Decision rationale

The project should prioritize transparent, explainable workflows and realistic demo data instead of pretending to connect to live public infrastructure.
